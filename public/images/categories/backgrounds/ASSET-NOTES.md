# Category background assets

`src/components/GameCategoryCard.tsx` maps each game slug to one local image and an individual focal position. These are recognizable game-specific promotional or card images for the requested local school prototype; not all source hosts are the rights holders.

| Game | Local background | Source |
| --- | --- | --- |
| Beyblade | `beyblade-x.webp` | [BEYBLADE X official site](https://au.beyblade.com/index.html) |
| Cardfight!! Vanguard | `cardfight-vanguard.jpg` | [Cardfight!! Vanguard official site](https://en.cf-vanguard.com/animation/) |
| Cookie Run | `cookie-run-kingdom.jpg` | [Pocket Gamer image](https://media.pocketgamer.com/artwork/ra-92932-1672149720/7-games-like-cookie-run-kingdom.jpg) |
| Cyberpunk | `cyberpunk-2077.jpg` | [Cyberpunk 2077 image](https://i.blogs.es/de55cf/unnamed-1-/1366_2000.jpeg) |
| Riftbound | `riftbound-jinx-art.jpg` | Cropped from the Jinx card image at [RiftDecks](https://riftdecks.com/cards/details-jinx-rebel) |
| Pokémon | `pokemon-pikachu.png` | [TCGplayer Pikachu image](https://mktg-assets.tcgplayer.com/content/pokemon/_2026/JAN/23/Pikachu.png) |
| Magic: The Gathering | `magic-planeswalker.jpg` | [Wizards of the Coast card art](https://magic.wizards.com/en/news/feature/creating-niko-aris-2020-12-14) |
| Flesh and Blood | `flesh-and-blood-kassai.webp` | [Star City Games card art](https://articles.starcitygames.com/flesh-and-blood/meet-all-six-heroes-coming-in-flesh-and-bloods-heavy-hitters/) |

The Riftbound background is authentic Jinx card artwork, cropped to keep the character prominent. The other image files from the previous SVG-only pass remain in this directory but are no longer used by category cards.
